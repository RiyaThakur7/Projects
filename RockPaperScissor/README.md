# Rock Paper Scissors Game

## Overview

This project is a simple **Rock Paper Scissors game** built using **Python**. The user plays against the computer, and the computer randomly selects rock, paper, or scissors. The program then determines the winner based on the game rules.

## Features

* User vs Computer gameplay
* Random computer choice using Python's `random` module
* Simple command-line interface
* Displays the winner after each round

## Technologies Used

* Python
* Random module

## How to Run

1. Make sure Python is installed on your system.
2. Download or clone this repository.
3. Open the project folder in terminal or command prompt.
4. Run the program using:

python rock_paper_scissor.py

## Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
